\## Analisis nilai siswa

program python  sederhana untuk menganalisis nilai siswa, dari rata-rata per siswa,menemukan kelulusan, serta menemukan siswa terbaik



\## Fitur

* Menghitung rata-rata tiap siswa
* menemukan status lullus/tidak lulus tiap siswa
* menghitung rata-rata seluruh kelas
* menemukan siswa dengan nilai tertinggi



\## Cara menjalankan

1. Pastikan sudah install python3
2. clone repo ini
3. jalankan: 'python main.py'



\## Contoh output



=== Laporan Nilai Siswa ===

Budi     : 84.33 : Lulus

Ani      : 91.67 : Lulus

Citra    : 71.00 : Tidak lulus

==============================

rata-rata kelas: 82.33

siswa terbaik: Ani (91.67)
